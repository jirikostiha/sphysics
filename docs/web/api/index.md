# SPhysics API Reference

Welcome to the **SPhysics** API Reference.

SPhysics is designed around .NET generic math, offering allocation-free, static physical formulas and quantities.

## Namespaces

- **`SPhysics`**: Base SI physical quantities (length, mass, time, temperature, current, etc.), kinematics (velocity, acceleration), dynamics, forces (friction, drag, gravity), energy (kinetic, potential, gravitational), power, and rigid body mechanics.
- **`SPhysics.CelestialMechanics`**: Orbital calculations including barycenter, escape velocity, mean anomaly, true anomaly, mean motion, orbital period, and orbital eccentricity.
